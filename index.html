Export / import

Save files to

CSV, backups and images go to the "Bird Flight Directions" folder in your Google Drive. claude.ai asks once before this page can use Drive.

Each file opens your phone's share menu, so you can save it to Google Drive, Files, LINE or email.

Data is stored online with this link, so your phone and Mac show the same records. Without signal, records wait on this device and are sent when you are back online. The sync status is shown under the site name.

Data is stored in this browser only. Move it between phone and Mac with a JSON backup, and back up regularly.

Settings

Direction resolution

Directions you tap are relative to true north. A phone compass uses magnetic north, a few degrees off in China and Thailand.
